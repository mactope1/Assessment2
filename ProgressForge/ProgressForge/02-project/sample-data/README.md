# Safe Sample Data

These files contain **fictional demonstration records**. They are included so ProgressForge can be tested without using real personal fitness data.

Files:

- `exercises_sample.json`
- `routines_sample.json`
- `workouts_sample.csv`
- `bodyweight_sample.csv`
- `nutrition_sample.csv`
- `settings_sample.json`

The sample dates were chosen around September 2026 so the example Weekly Forge Report has enough current and previous seven-day records when tested during project development.

Do not describe these fictional records as real personal training history.

If you want to test with the sample files manually, make a backup of your personal `data/` folder first, then copy the sample CSV/JSON contents into the matching files under `data/`. Restore your personal data afterward.
